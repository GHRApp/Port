## 🚀 Sobre

Portfólio profissional desenvolvido para apresentar minha trajetória na área de **Segurança da Informação** e **Cloud Computing**, com foco em **AWS Cloud Security**.

### ✨ Features

- 🎬 **Terminal Boot Animation** - Experiência imersiva de SSH login
- 🟢 **Matrix Background** - Animação de fundo temática otimizada com Canvas API
- 🌐 **Sistema Bilíngue** - Suporte completo PT/EN com troca dinâmica
- 🤖 **AI Chatbot Assistant** - Assistente interativo com informações sobre minha carreira
- 📊 **Jira-Style Knowledge Board** - Visualização criativa de tech stack
- 📱 **Fully Responsive** - Design adaptativo para todos os dispositivos
- ♿ **Acessível** - WCAG AA compliant com suporte a leitores de tela
- 🔒 **Seguro** - Content Security Policy, proteção XSS, email ofuscado

## 🛠️ Tecnologias

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla - sem frameworks)
- **Animações**: Canvas API, requestAnimationFrame
- **Arquitetura**: SPA (Single Page Application)
- **Hospedagem**: GitHub Pages
- **Performance**: Otimização de assets, lazy loading, cache de DOM

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/GHRApp/Port.git

# Entre no diretório
cd Port

# Abra com um servidor local (recomendado)
# Opção 1: Python
python -m http.server 8000

# Opção 2: Node.js
npx http-server

# Opção 3: VS Code Live Server
# Clique direito em index.html > "Open with Live Server"

# Acesse http://localhost:8000
```

## 🔐 Segurança

Este portfólio implementa várias boas práticas de segurança web:

- ✅ Content Security Policy (CSP)
- ✅ Proteção contra Tabnabbing (`rel="noopener noreferrer"`)
- ✅ Prevenção de XSS (uso correto de `textContent`)
- ✅ Email ofuscado via JavaScript
- ✅ Assets locais (sem CDNs externos)
